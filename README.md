# Fintech Credit Risk Analysis Model 💳

## 📌 Project Overview
This project simulates a **Credit Risk Assessment Model** used by Fintech companies to evaluate loan applicants. It segments customers based on **CIBIL Score**, **Debt-to-Income (DTI) Ratio**, and **Loan-to-Value (LTV)**.

## 📊 Key Metrics Analyzed
* **Debt-to-Income (DTI) Ratio:** Assessing a borrower's ability to manage monthly payments.
* **Credit Scoring:** Categorizing applicants into 'Prime', 'Sub-Prime', and 'High Risk'.
* **Default Probability:** Identifying high-risk profiles to minimize Non-Performing Assets (NPA).

## 🛠️ Financial Skills Applied
* **Risk Modeling:** Calculation of EMI vs. Monthly Income.
* **Portfolio Analysis:** Segmentation of loan book by risk category.
* **Tools:** Advanced Excel (Logical Functions) & SQL for data querying.
